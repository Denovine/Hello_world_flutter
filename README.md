# hello_world_app

This repository is a simple Flutter "Hello World" application and supporting documentation for running the app locally and running a tiny standalone API example script.

**What's included**
- **Flutter app:** `lib/main.dart` — the default counter app generated by Flutter.
- **Small API example script:** `bin/api_example.dart` — a small Dart script that performs a quick HTTP GET to a public JSON test endpoint.
- **Documentation:** `docs/` contains prompts, reflections, common errors, and references.

**Quick Links**
- Run app: `flutter run`
- Run API example: `dart run bin/api_example.dart`
- Docs: `docs/AI_PROMPTS.md`, `docs/COMMON_ERRORS.md`, `docs/RESOURCES.md`

**Overview of the chosen tech**
This project uses Flutter for building cross-platform UI (Windows/macOS/Linux/iOS/Android/web). Dart is the programming language. We include the `http` package for the small API example script.

**Setup (Windows)**
1. Install Flutter: follow the official guide at https://docs.flutter.dev/get-started/install/windows
2. Ensure `flutter` is on your `PATH` and `flutter doctor` is clean. Install Android SDK or enable Windows desktop support if targeting Windows.
3. From the project root run:

```powershell
flutter pub get
```

4. To run the Flutter app on the default device (e.g. connected Android emulator or Windows desktop):

```powershell
flutter run
```

5. To run the small standalone API example (requires Dart SDK available via Flutter):

```powershell
dart run bin/api_example.dart
```

Note: On Windows, you can also run the app specifically on the Windows desktop target with `flutter run -d windows` if desktop support is enabled.

**Minimal working example**
- The Flutter app is `lib/main.dart`. It is the default counter app: press the + FAB to increment the counter.
- The quick API example is `bin/api_example.dart`. It fetches a JSON object from `https://jsonplaceholder.typicode.com/todos/1` and prints the response.
